# Dog vs Cat Classifier

A Flask web app that classifies an uploaded image as a cat or a dog using a TensorFlow/Keras model. The training script builds a transfer-learning model based on MobileNetV2.

## Requirements

- Python 3.11 (the version used by the project's current virtual environment)
- The packages listed in `requirements.txt`
- A dataset arranged as described below

## Project structure

```text
.
├── app.py
├── train.py
├── requirements.txt
├── dog_cnn.keras             # Generated by training; not committed
├── dataset/                  # Local training and test images; not committed
│   ├── training_set/
│   │   ├── cats/
│   │   └── dogs/
│   └── test_set/
│       ├── cats/
│       └── dogs/
├── static/
│   └── style.css
└── templates/
    └── index.html
```

The directory names and class names must match this layout. `train.py` uses 20% of `training_set` for validation and evaluates the model using `test_set`.

## Setup

From the project directory, create and activate a virtual environment on Windows:

```powershell
py -3.11 -m venv env
.\env\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell prevents environment activation, run the commands below with the virtual environment's Python directly:

```powershell
.\env\Scripts\python.exe -m pip install -r requirements.txt
```

Place the dataset in the structure shown above before training. The first training run may download MobileNetV2's ImageNet weights.

## Train the model

```powershell
python train.py
```

Training saves the best model as `dog_cnn.keras` in the project directory and reports its test accuracy.

## Run the web app

The app expects `dog_cnn.keras` in the project directory. Train the model first if the file is not present.

```powershell
python app.py
```

Open <http://127.0.0.1:5000> in a browser and upload an image to get a prediction.

## Git ignore notes

`.gitignore` excludes the local virtual environments, the full `dataset/` directory, Python bytecode, and the generated `dog_cnn.keras` model. These files will need to be recreated or supplied separately on another machine. Git ignore rules do not remove files that were already committed or are already tracked; untrack any such files separately before pushing.
